# Signaler un résultat de test

Les wikis GitHub n'acceptent pas les pull requests. Signalez les résultats en ouvrant une [Issue](https://github.com/imanass/webetu-issue--wiki/issues).

Incluez toutes les informations suivantes :

- Modèle de l'appareil
- Version Android
- ROM : stock ou personnalisée
- Root : oui ou non
- Méthode utilisée
- Version de WebEtu
- Source du XAPK
- Résultat, y compris tout message d'erreur
- Capture d'écran, après avoir masqué les informations personnelles

Vous pouvez utiliser ce texte comme corps de l'Issue :

```text
Modèle de l'appareil :
Version Android :
ROM (stock/personnalisée) :
Root (oui/non) :
Méthode utilisée :
Version de WebEtu :
Source du XAPK :
Résultat/erreur :
Capture jointe (oui/non) :
```
