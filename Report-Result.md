# Report a test result

GitHub Wikis do not accept pull requests. Report test results by opening an [Issue](https://github.com/imanass/webetu-issue--wiki/issues).

Include all of the following:

- Device model
- Android version
- ROM: stock or custom
- Root: yes or no
- Method used
- WebEtu version
- XAPK source
- Result, including any error message
- Screenshot, with personal information hidden

You can use this text as the Issue body:

```text
Device model:
Android version:
ROM (stock/custom):
Root (yes/no):
Method used:
WebEtu version:
XAPK source:
Result/error:
Screenshot attached (yes/no):
```
