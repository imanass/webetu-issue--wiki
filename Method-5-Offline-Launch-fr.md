# Méthode 5 - Lancement hors ligne

## Étapes

1. Effacez les données de l'application WebEtu.
2. Désactivez le Wi-Fi et les données mobiles.
3. Lancez l'application.
4. Reconnectez-vous au réseau lorsque l'écran de connexion apparaît.
